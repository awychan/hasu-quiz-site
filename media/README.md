# media/ ─ 出題データの置き場所（フォルダ連動）

サイトはこのフォルダの中身を読んで、回・ジャンル・問題の画面を自動で組み立てます。
Google Drive の共有フォルダ「出題用サイト_媒体」の中身（第1回 …）を、そのままここに同期またはコピーしてください。
コードや設定の編集は不要です。

```
media/
└ 第1回/                                  ← 回。第〇回選択画面に1枚ずつ並ぶ
   ├ 読み込み用ファイル.txt               ← 任意。scripts/make_list.py が作る（下記）
   ├ 楽曲・音声_イントロ_減点方式/         ← カテゴリ_ジャンル名_方式
   │  ├ 第1問/
   │  │  ├ 音声1_ver1.mp3                 ← 3点（最初に流す）
   │  │  ├ 音声1_ver2.mp3                 ← 2点
   │  │  └ 音声1_ver3.mp3                 ← 1点
   │  └ 第2問/ …
   ├ 楽曲・歌詞_歌詞_減点方式/
   │  └ 第1問/
   │     ├ 歌詞1_ver1.txt  歌詞1_ver2.txt  歌詞1_ver3.txt   ← 3点→2点→1点の歌詞（文字）
   │     ├ 回答1.txt                                      ← 曲名
   │     └ 楽曲1.mp3                                      ← 回答後に流す
   ├ 動画_せーはす_点数方式/
   │  ├ 初級/  動画1_問題.mp4  動画1_回答.mp4 …           ← 初級=1点
   │  ├ 中級/  …                                          ← 中級=2点
   │  └ 上級/  …                                          ← 上級=3点
   └ 文章_リンクラ_減点方式/
      └ 第1問/
         ├ 画像1_ver1.png                 ← 問題のみ（3点）
         ├ 画像1_ver2.png                 ← ヒント1（2点）
         ├ 画像1_ver3.png                 ← ヒント2（1点）
         └ 画像1_回答.png                 ← 回答
└ 第2回/ …
```

## 名前の規則

| 名前 | サイトが読み取るもの |
| --- | --- |
| `第1回/` `第2回/` | 回。数字順に並ぶ |
| `カテゴリ_ジャンル名_方式/` | カテゴリ（楽曲・音声／楽曲・歌詞／動画／文章）、パネルに出す名前、減点方式か点数方式か。並び順を指定したいときは先頭に `01_` のような番号を付ける（例：`01_楽曲・音声_イントロ_減点方式`） |
| `第N問/` | 問題番号 |
| `初級/` `中級/` `上級/` | 点数方式の級（1点／2点／3点）。ある級だけでよい |
| `…_ver1` `…_ver2` `…_ver3` | 3点 → 2点 → 1点 の段階（音声・歌詞・画像） |
| `…_問題` `…_回答` | 問題動画と回答動画の対。文章の回答画像も `_回答` |
| 拡張子 | mp3・m4a・wav は音声、mp4・mov・webm は動画、png・jpg は画像、txt は文字。カテゴリ名と食い違うときは拡張子を優先 |
| `_` や `.` で始まる名前 | サイトが無視する（メモ用のテキストなどに使える） |

## 読み込み用ファイル.txt

ブラウザはフォルダの中身を自分では一覧できません。会場で使う `python3 -m http.server` はフォルダ一覧を返せるので、
ローカルで動かす間はこのファイルが無くても動きます。別のサーバーに置くときや一覧を固定したいときは、次を1回実行してください。

```bash
python3 scripts/make_list.py
```

各回フォルダの中に、その回のファイル一覧（1行1件）が書き出されます。ファイルを足したら、また実行してください。

## 置いたあとの確認

サーバーを起動してブラウザで開くと、第〇回選択画面に回が並びます。
ファイルが足りないボタンは「なし」と表示され、押せません（動作は止まりません）。
