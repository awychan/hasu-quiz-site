# media/ ─ 出題データの置き場所（フォルダ連動）

サイトはこのフォルダ（または `drive/` リンクの先の Google Drive「出題用サイト_媒体」）の中身を読んで、回・ジャンル・問題の画面を自動で組み立てます。
コードや設定の編集は不要です。下の例の名前はすべて**ダミー**です（実際の曲名などは書かないでください。このファイルは公開リポジトリにあります）。

```
media/
└ 第1回/                                     ← 回。第〇回選択画面に 1 枚ずつ並ぶ
   ├ 楽曲・音声_イントロ_減点方式/            ← カテゴリ_ジャンル名_方式
   │  ├ 第1問/
   │  │  ├ 01イントロ_①.mp3                  ← ヒント① = 5点（最初に流す）
   │  │  ├ 01イントロ_②.mp3                  ← ヒント② = 2点
   │  │  ├ 01イントロ_③.mp3                  ← ヒント③ = 1点
   │  │  ├ 01イントロ_解答.mp3                ← 任意：答え合わせで流す音声
   │  │  └ _曲名.txt                         ← 答え（ファイル名がそのまま画面に出る。中身は空でよい）
   │  └ 第2問/ …
   ├ 楽曲・歌詞_歌詞_減点方式/
   │  └ 第1問/
   │     ├ 01歌詞_①.png  01歌詞_②.png  01歌詞_③.png   ← 歌詞の 1 枚絵（最新の段階だけを全面に出す）
   │     ├ 01歌詞_解答.png                             ← 答えの画像
   │     └ 01歌詞_解答.mp3                             ← 答え合わせで流す楽曲
   ├ 動画_ダミー_点数方式/
   │  ├ 初級/                                 ← 初級 = 1点
   │  │  ├ 動画1_問題.mp4   動画1_正解.mp4    ← 問題動画と正解動画の対（幹「動画1」で組む）
   │  │  └ 動画2_問題.mp4   動画2_正解.mp4    ← 1 つの級フォルダに対をいくつ置いてもよい
   │  ├ 中級/ …                               ← 中級 = 2点
   │  └ 上級/ …                               ← 上級 = 5点
   └ 文章_ダミー_減点方式/
      ├ 第1問/
      │  ├ 01画像_①.png  01画像_②.png  01画像_③.png    ← 問題のみ → ヒント → ヒント
      │  └ 01画像_解答.png
      ├ 第2問/
      │  ├ 02声_①.mp3  02声_②.mp3  02声_③.mp3          ← ヒントが音声でもよい（問題ごとに判断）
      │  ├ 02声_解答.mp4                               ← 答えが動画でもよい
      │  └ _曲名 人名.txt
      ├ 問題3_減点方式/                       ← 問題フォルダに方式を付けてもよい（下記）
      │  ├ 03画像_①.png                       ← ヒントが 1 つだけの問題は ① = 5点
      │  └ 03画像_解答.png
      ├ 第4問/
      │  ├ 04音声_①.mp3 … 04音声_⑳.mp3        ← 4 本以上のヒントも可。音声が tierPoints より多く解答ファイルが無いと「逆転」の格子画面
      │  └ _題名.txt
      └ サブジャンルA/                        ← サブジャンル（級でも 第N問 でもない名前のフォルダ）
         ├ 第1問/  …                          ← サブジャンルの中に問題フォルダ
         └ 初級/  x_①.png  x_解答.png         ← 級フォルダに直接ファイルを置けば、それが 1 問
└ 第2回/ …
```

## 名前の規則

| 名前 | サイトが読み取るもの |
| --- | --- |
| `第1回/` `第2回/` | 回。数字順に並ぶ |
| `カテゴリ_ジャンル名_方式/` | カテゴリ（楽曲・音声／楽曲・歌詞／動画／文章）、パネルに出す名前、ジャンルの方式（`減点方式`／`点数方式`）。並び順を指定したいときは先頭に `01_` のような番号を付ける。カテゴリや方式の無い名前（例：`ダミー`）でも読める |
| サブジャンル `任意の名前/` | ジャンルと問題の間のフォルダで、級でも問題フォルダでもないもの。選択画面の見出しになる。ジャンルの下はフォルダ 3 段まで読める（例：`サブジャンル/上級/第1問/`）。それより深いフォルダは読まず、警告（`too-deep`）を出す。`01_サブジャンル` `1 サブジャンル` のように先頭に番号を付けると、その番号順に並ぶ（問題フォルダとは読まない） |
| `初級/` `中級/` `上級/` | 点数方式の級。**上級 = 5点／中級 = 2点／初級 = 1点**（`js/config.js` の `tierPoints` と `levels`）。画面の並びは 初級 → 中級 → 上級。ある級だけでよい |
| `第N問/` `問題N/` `N/` | 問題フォルダ。N が問題番号（`第１問` のような全角数字も可）。並びは番号の自然順（第10問 は 第9問 の後） |
| `問題N_減点方式` `問題N_点数方式` `問題N_逆転` `問題N_3点` | 問題ごとの方式。ジャンルの方式より優先。`_点数方式_3点` のように点数も付けられる。接尾辞が食い違うときは並び順に関係なく **`_逆転` ＞ `_減点方式` ＞ `_点数方式`・`_N点`** の順に採り（`_逆転` は減点方式で、`_点数方式` `_N点` とは両立しない）、警告（`suffix-conflict`）を出す。`_N点` が複数あるときは左端のもの。**知らない接尾辞は減点方式として読み、警告を出す**（`第N問_…` `問題N_…` でサブフォルダの無いときだけ。番号だけの `N_…` やサブフォルダを持つものはサブジャンル）。名前を変えても問題の番号（進捗の保存先）は変わらない |
| `…_①` `…_②` `…_③` …（`①`〜`⑳`、`㉑`〜`㉟`） | ヒントの段階。出す順番。**減点方式は ① = 5点、② = 2点、③ = 1点**、④ 以降は点数なし。`…_ver1` `…_ver2` … も同じ意味 |
| `…_解答` | 答えのファイル。`_回答` `_正解` `_答え` `_answer` でもよい。画像・音声・動画のどれでも、同じ問題に複数（例：`_解答.png` と `_解答.mp3`）置いてもよい |
| `…_問題` | 問題動画（`_正解` と対にする）。`_question` でもよい |
| `_曲名.txt` | **メモ**＝答えの文字。段階の印も答えの印も無い `.txt` はメモで、ファイル名（先頭の `_` と `.txt` を除く）が答えとして画面に出る。`_` が無くてもよい。`.txt` の「答え」「解答」「①」「_verN」は、**名前の先頭か `_` 空白 `-` の直後にあるときだけ**印として読む（`ダミーの答え.txt` `曲名①.txt` は曲名どおりのメモ。`題名_①.txt` は段階、`題名_答え.txt` は答えの文字ファイル）。先頭が `_` の `.txt` は段階にしない。逆転の問題では中身（1 行目に題名、続けて ①〜⑳ の行）も使う |
| 幹 | ファイル名から印（`_①` や `_解答` など）を 1 つ取り除いた残り。**1 つの問題フォルダの中は同じ幹にそろえる**（例：`01画像_①.png` と `01画像_解答.png`）。幹が複数あるフォルダは幹ごとに別の問題になる（対動画のため）。`第5問/` のような番号付きの問題フォルダの中に幹が複数あるときは、問題の番号（進捗の保存先）は `5-1` `5-2` … になる（他の `第1問` などとぶつけないため） |
| 拡張子 | mp3・m4a・wav・aac・ogg・flac は音声、mp4・mov・webm・m4v は動画、png・jpg・gif・webp は画像、txt は文字。大文字（`.PNG`）も可。画面はジャンルではなく**問題ごと**にファイルの種類で決まる |
| 全角数字だけが違う名前（`第1問` と `第１問`） | 同じ名前として 1 つにまとめて読む（後のフォルダのファイルも同じ問題に入る）。名前が重複しているので警告（`duplicate-name`）を出す。NFC と NFD の違いだけなら警告しない |
| `.` で始まる名前、`_` で始まるフォルダ | 無視する（`_下書き/` などに使える） |
| `_` で始まる `.txt` 以外のファイル | 無視する |
| 空のフォルダ | 画面には出さず、件数にも入れない（読み込みレポートと check_media の警告にだけ出る） |
| 読めなかったフォルダ | フォルダ一覧を取得できなかった（`unreadable`）、深すぎて中のフォルダを読んでいない（`too-deep`）ときは、空のフォルダ扱いにせず、その警告だけを出す |

### 廃止した規則（以前の README から）

- 名前の末尾の数字を段階として読む規則（`画像1.png` `画像2.png` …）は**廃止**。段階は必ず `①②③` か `_verN` で付ける（`動画1_問題` と `動画2_問題` を区別するため）。
- `④`（`_ver4`）＝ 回答 の規則は**廃止**。④ は 4 番目のヒント。答えは `_解答` などで付ける。
- 点数の 3点／2点／1点、級の 初級1点／中級2点／上級3点 は**廃止**。点数は `js/config.js` の `tierPoints: [5, 2, 1]` で決まる。
- `_` で始まる `.txt` を無視する規則は**廃止**（メモ＝答えとして読む）。

## 読み込み用ファイル.txt

ブラウザはフォルダの中身を自分では一覧できません。会場で使う `python3 -m http.server` はフォルダ一覧を返せるので、
ローカルで動かす間はこのファイルが無くても動きます。別のサーバーに置くときや一覧を固定したいときは、次を実行してください。

```bash
python3 scripts/make_list.py            # media/ の各回フォルダに書く
python3 scripts/make_list.py --stdout   # 書かずに表示だけ
```

- 1 行 1 件、回フォルダからの相対パス。**フォルダも `フォルダ名/` の行で書きます**（空フォルダを警告に出すため）。メモの `_曲名.txt` も含みます。名前は NFC にそろえます。
- **一覧ファイルがあると、サイトはそれだけを読みます。** ファイルを足したり名前を変えたりしたら必ず実行し直してください（古い一覧が新しいファイルを隠します）。
- **Google Drive の中（`drive/` リンクの先、`~/Library/CloudStorage`、`~/Google Drive`）では実行できません**（運営の共有フォルダに書き込まないため）。回フォルダや一覧ファイルが Drive へのシンボリックリンクのときも、何も書かずに止まります。Drive を使うときは一覧ファイル無しで、サーバーのフォルダ一覧で読みます。

## 置いたあとの確認

```bash
node scripts/check_media.mjs --base media --round 第1回        # フォルダを直接読む
node scripts/check_media.mjs --url http://127.0.0.1:8765        # サーバー経由（サイトと同じ読み方）
```

問題ごとの 1 行表、警告（割り当てられないファイル・空フォルダ・答えの無い問題・段階の抜け・接尾辞の食い違い・名前の重複・読めない／深すぎるフォルダ など）、名前を含まないパターン集計が出ます。
割り当てられないファイルがあると終了コード 1 です。**出力には答えが含まれるので、公開の場所には貼らないでください。**
