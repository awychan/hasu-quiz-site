出題用サイト フォルダ連動の仕組み

仕様書「シート5」が求めているのは、フォルダを置くだけでサイトの中身が決まる仕組みです。回（第1回・第2回…）、ジャンル、問題、点数ごとのファイルを、すべてフォルダ名とファイル名から読み取ります。このページでは、その流れを図と画面写真で説明します。

いま（9/25 版）

ジャンルと問題数は js/data.js に書いてあり、ファイル名の規則だけが決まっている。ジャンルを足す・問題数を変えるにはコードを編集する。回（第〇回）の概念はない。

シート5 の提案

第1回/ のようなフォルダを作り、その中にジャンルフォルダと問題ファイルを置く。サイトは起動時にフォルダ構成を読み、回の選択画面 → TOP → 各問題画面を自動で組み立てる。コードの編集は不要。

① 全体の流れ

仕様書の流れ図（フォルダ構成取得 → 第〇回選択 → ジャンル取得 → TOP → 問題取得 → 各種問題画面）を、サイトの部品に置き換えたものです。読み込みは最初の1回だけで、以降の画面はその結果から作られます。

② 仕様書「シート5」の内容

左が処理の流れ図、右がフォルダ構成の例です。黄色の行が、ジャンルフォルダ名の付け方（カテゴリ_ジャンル名_方式）を示しています。

④ 読み込み用ファイル.txt の役割

ブラウザは自分ではフォルダの中身を一覧できません。そこで各回のフォルダに、その回に含まれるファイルを1行1件で書いたテキストを置きます。これが仕様書の「読み込み用ファイル.txt」です。

楽曲・音声_イントロ_減点方式/第1問/音声1_ver1.mp3
楽曲・音声_イントロ_減点方式/第1問/音声1_ver2.mp3
楽曲・音声_イントロ_減点方式/第1問/音声1_ver3.mp3
動画_せーはす_点数方式/初級/動画1_問題.mp4
動画_せーはす_点数方式/初級/動画1_回答.mp4
…

手で書く必要はありません。付属の小さなスクリプトを1回実行すると、フォルダを走査してこのファイルを作ります。さらに、会場で使う python3 -m http.server はフォルダ一覧を返せるので、ローカルで動かす間はテキストが無くてもサイトが直接フォルダを読めます。テキストは「別のサーバーに置くとき」や「一覧を固定したいとき」の保険です。

⑤ 画面との対応

フォルダの各部分が画面のどこに出るかを、現在のサイトの写真に番号で示します。

⑥ 運営の手順

  1. 回のフォルダを作る

    第1回/ のように、サイトのフォルダ（index.html と同じ階層）に置きます。

  2. ジャンルフォルダを作る

    名前を カテゴリ_ジャンル名_方式 の形にします。例：動画_With×MEETS_点数方式

  3. 問題ファイルを置く

    第1問/（点数方式は 初級/ など）の中に、_ver1〜3 または _問題/_回答 の名前で保存します。

  4. 一覧を作る（任意）

    スクリプトを1回実行すると各回に 読み込み用ファイル.txt ができます。ローカルサーバーで使うだけなら省略できます。

  5. サーバーを起動して確認

    python3 -m http.server 8765 --bind 127.0.0.1 を実行し、ブラウザで開くと回の選択画面から始まります。

⑦ 実装前に確認したい点

  • 黄色の例フォルダの中身「楽曲・音声_イントロ_減点方式」の中に画像（png）が入っていますが、音声ジャンルの例としては mp3 のはずです。サイトは拡張子で再生方法を決めるので動作上は問題ありませんが、意図を確認したいです。
  • 文章の回答画像の名前進行は 3点→2点→1点→回答 なので、ver1〜ver3 のほかに回答用の画像が1枚必要です。画像1_回答.png を提案します。
  • 歌詞ジャンルの文字データ歌詞は画像ではなく文字で出します。歌詞1_ver1.txt〜_ver3.txt、回答1.txt、楽曲1.mp3 の構成を提案します。
  • 上級フォルダ例には初級・中級しかありません。初級＝1点、中級＝2点、上級＝3点として、ある級だけを表示する想定で進めます。
